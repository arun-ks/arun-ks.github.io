# Portfolio icon prompts

These prompts produced the representative images in `public/portfolio/`. Each image was generated independently with the same visual system so the set would feel cohesive.

## Multiple News Live

```text
Use case: stylized-concept
Asset type: compact portfolio card illustration
Primary request: representative visual for an app that displays multiple live news broadcasts simultaneously
Subject: four small broadcast screens arranged as a clean mosaic, subtle live signal waves
Style/medium: polished flat editorial illustration with slight dimensional depth
Composition: centered square icon, bold simple silhouette, readable at 64px
Color palette: deep navy background, cyan, coral, warm yellow and off-white accents
Constraints: no words, no letters, no logos, no watermark, no photorealism
```
